# Reproduction guide

## What can be rerun

The supplied Python code regenerates the overview, four legacy summary plots, and—if its absent trial input is recovered—the historical validity plot. Native TikZ sources regenerate ten editable figures from supplied CSV values and drawing instructions. The additional exact scalar benchmark is documented in [`scalar_frontier.md`](scalar_frontier.md); it independently implements the declared reference.

Read the protocol directly in [`Extended Experiments`](../extended_experiments.md). It requires no document build. The original historical simulation studies cannot be rerun because their drivers and complete trial records were not supplied; [`provenance.md`](provenance.md) identifies the missing material.

## Dependencies

- Python 3.10 or later, NumPy, Matplotlib, Pillow, and pypdf. Install `requirements.txt` in your chosen environment. Pillow and pypdf validate generated outputs.
- A TeX distribution providing `pdflatex`, TikZ/PGFPlots 1.18, `standalone`, `newtxmath`, `fontenc`, Times (`ptm`), `amsmath`, and `amssymb` for the figure sources.
- Poppler's `pdftoppm` for the PNG previews produced by the legacy PGF plotting script and the `--previews` task.

The manuscript-synchronization validation on 29 September 2026 used Python 3.12.14, NumPy 2.3.5, Matplotlib 3.10.8, and pdfTeX from TeX Live 2023/Debian. TeX setup is platform-specific; the companion source does not depend on private runtime paths.

## Portable build entry point

Run these commands from the repository root:

```bash
python -m pip install -r requirements.txt
python scripts/reproduce.py --python
python scripts/reproduce.py --pgf --tikz --previews
```

With no flags, `reproduce.py` performs the Matplotlib overview task. Flags can be combined. `--output PATH` selects a distinct output directory; by default all generated files and logs are under `build/reproduction/`. The helper copies supplied assets into that directory before execution, preserving the packaged figures. It replaces the historical hard-coded `/usr/bin/pdftoppm` path only in its temporary copy of `plot_figures.py`, using the executable found on `PATH`.

| Task | Generated files under the output directory |
| --- | --- |
| `--python` | `figures/joint_service_overview.pdf` and `.png`. |
| `--pgf` | PDF and PNG versions of `joint_exclusion_geometry`, `wireless_confidence_trace`, `certification_costs`, and `execution_stopping_costs`. |
| `--tikz` | One PDF beside each of the ten copied standalone `.tex` wrappers. |
| `--previews` | Four 160-dpi PNGs in `figures/tikz/rendered/`: `validity_completion_outcomes`, `v37_cost_comparisons`, `v37_promise_reservations`, and `v42_deadline_instrumentation_frontier`. |

Combine `--tikz --previews` to build fresh native PDFs and then render the Markdown illustrations. `--previews` alone renders the supplied canonical PDFs. The old architecture and protocol-PDF tasks have been removed.

`build_results.json` records each task's exit code, log, output-validation results, and combined success. Before each task, the helper removes that task's expected products so a copied or stale preview cannot mask a failed producer. A zero process exit is insufficient: every expected PDF must have a complete header/trailer, parse strictly, and contain readable page streams; every PNG must have a complete final chunk, pass its integrity check, and decode successfully. Missing or invalid products make the command fail. No task imputes observations or executes the blocked validity script.

Run the build-validation regression tests with:

```bash
python -m unittest discover -s tests -v
```

## Supplied validity script

`figures/plot_validity_study.py` is retained unchanged. It expects `methods/validity_study/trial_results.csv`, with method, budget, immediate/issued/correct/unresolved/wrong fields, and checks 720 trials per budget for the audited-sufficient method. That file was not supplied. The script's `FileNotFoundError` was verified; synthetic replacement rows cannot establish the missing trial histories.

The native `validity_completion_outcomes.tikz` figure instead renders the supplied `validity_counts.csv`. Its provenance identifies the values as a published-count transcription.
